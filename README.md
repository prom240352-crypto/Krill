# Krillion · The Daily Dive (Online Multiplayer Edition)

Full-stack **Node.js + Express + Socket.IO** server hosting the pixel-exact Krillion game and **real-time multiplayer Puffer Party** (Public Rooms, Host Room, Join by 4-Letter Code, synced fuse & turns).

## Deploy Free on Render.com (No Credit Card Needed)
1. Create a new GitHub repository and upload all files from this folder (`server.js`, `package.json`, `render.yaml`, `public/index.html`).
2. Go to [https://render.com](https://render.com) -> **New +** -> **Web Service** -> connect your GitHub repo.
3. Keep Build Command `npm install` and Start Command `npm start`, select **Free** plan, and click **Create Web Service**.
4. Share your `https://<your-app>.onrender.com` link with friends!

## Run Locally (PC / Termux)
```bash
npm install
npm start
# Open http://localhost:3000
```
